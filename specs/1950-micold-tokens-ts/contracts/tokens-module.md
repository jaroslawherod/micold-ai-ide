# Contract: `tokens.generated.ts`

1. Line 1: `// GENERATED by micold-tokens-ts from crates/micold-core/src/tokens/. Do not edit.`
2. Then, in this order, `export const colors`, `typeScale`, `shape`, `elevation`, `motion`, `state`, `spacing`, each `= { ... } as const;` (shapes: data-model.md).
3. Two-space indent, one key per line, trailing commas, `\n` line ends, file ends with one `\n`.
4. Colour values are lowercase `#rrggbb`, equal to `stylesheet()`'s value for the same role and scheme.
5. `colors.light` and `colors.dark` have identical key sets.
6. Binary: `micold-tokens-ts <path>` writes atomically, exit 0; no argument prints to stdout; a write failure exits 1 naming the path and leaves no file.
7. Drift test: regenerated output `cmp`-equal to the committed file, else exit 1 printing the file path and the research.md regeneration command; a missing file fails.
