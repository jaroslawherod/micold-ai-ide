# Bug Report: Overview badge says "1 need action" instead of a singular

**Type**: Implementation drift plus spec gap — FR-012 required a count and an accessible label but not
that the words agree with the count; the code, tests and guide pinned the plural-only text.
**Severity**: Low
**Feature**: 813-worktree-overview (FR-012, User Story 2.4)
**Reported**: 2026-10-27 (found by the #1128 visual pass, `specs/1128-layout-redesign-docs/visual-pass.md`)
**Status**: **Patched**

## Description

With one location in the worst state the sidebar's Overview badge and tooltip read "1 need action" or
"1 need attention". Expected: "1 needs action" / "1 needs attention".

Reproduced on `origin/main` (728eb72): `features/overview.rs` `badge()` formats
`"{count} {words}"` with the fixed words "need action" / "need attention". The pinned test
`tests/overview.rs` `any_card_needing_action_gives_an_error_badge_counting_those_cards` asserted
`"1 need action"`; with the expectation changed to `"1 needs action"` it fails.

## Root cause

`badge()` (crates/micold-client/src/features/overview.rs) has no singular branch. The wording came
from tasks.md T034 / `contracts/ui.md` U2 (*N need action*), pinned by the user guide and tests.
