**Type**: Implementation drift

## Description
`review::anchor::tests::two_hundred_comments_locate_inside_the_budget` (T057, added in `ccdd1dc3`)
asserts `< 100 ms` wall clock in the debug test run. It reads 101-159 ms on a loaded Linux machine
and 107 ms on macOS CI (PR #1011), so it fails the gate for unrelated changes. A wall-clock budget
is a release-build number; feature 021 settled this in BUG-003 (budget tests are
`cfg_attr(debug_assertions, ignore)` and run in CI's "Test (type-ahead frame budget, release)").

assertion into the debug suite without the release-only treatment BUG-003 established.
